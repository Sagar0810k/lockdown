HOW LOCKING WORKS
1
You pick the distracting apps and a duration — or a “block until” time.
2
Phone goes silent via Do Not Disturb. Blocked apps open into a full-screen lock with a countdown.
3
When time is up, everything is restored automatically — even if you rebooted mid-session.
HONEST FINE PRINT
Emergency: Phone app and 911 always stay available - Lockdown never blocks calls.
Clock-proof: sessions run on the phone monotonic clock, so changing the time can't end a duration early.
Strict mode also blocks Settings & Play Store so the lock can't be switched off mid-session.
No app is unstoppable. A determined user can disable accessibility in system settings - a commitment device, not a vault.
On-device only. No account, no cloud, no tracking, no telemetry.
